# 😴 Sleep Quality Predictor Backend

A Flask-based backend application that predicts sleep quality using a trained machine learning model.

## ✨ Features
- Accepts sleep-related input data.
- Processes input using trained ML models.
- Predicts sleep quality.
- Uses pre-trained models and encoders.
- Provides prediction results through Flask API.

## 🛠️ Technologies Used
Python | Flask | Scikit-learn | Machine Learning | Pickle

## ⚙️ How to Run

```bash
pip install flask scikit-learn
python app.py
```

The Flask backend runs at `http://127.0.0.1:5000/`.
